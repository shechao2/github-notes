# FAQ 编写规范

> 目的：让每一条知识都能被检索到、被审核、被追溯，半年后接手的人不用问「这句是谁写的、依据在哪」。

## 一、字段定义（13 个，缺一不可）

| 字段 | 必填 | 说明 | 反例 |
|---|---|---|---|
| `id` | ✅ | `FAQ-001` 递增，永不复用 | 用问题当 ID |
| `category` | ✅ | 售前 / 售后 / 边界 | 写「其他」 |
| `question` | ✅ | **标准问法**：客户会怎么说，不是内部术语 | 「三电系统质保政策说明」 |
| `variants` | ✅ | 3—6 条同义问法，口语化 | 只写一个近义词 |
| `models` | ✅ | `S7` / `X3` / `L9` / `全车型` | 空着不写 |
| `scene` | ✅ | 售前价格、售后保养这类二级场景 | 「咨询」 |
| `phenomenon` | 售后必填 | 故障现象分类：充电 / 空调 / 制动 / 车机 / 续航 / 保养 / 三电质保 / 事故保险 / 救援 / 服务流程 / 配件价格 / 用车 / 故障诊断 / 轮胎 | 「其他问题」 |
| `answer` | ✅ | **1—3 句**，先给结论再给条件；数字必须有出处 | 一大段说明书 |
| `source` | ✅ | 用户手册页码 / 官网页面 / 业务确认 | 「网上查的」 |
| `owner` | ✅ | 具体到人（组-姓名），不写「客服部」 | 「管理员」 |
| `updated_at` | ✅ | 最后一次确认有效的日期 | 建库日期一直不改 |
| `status` | ✅ | 生效 / 待审核 / 停用 | —— |
| `tags` | ✅ | 2—5 个检索用标签 | 塞 20 个 |
| `priority` | ✅ | P0 安全与投诉 / P1 价格质保 / P2 一般咨询 | 全填 P0 |

## 二、标准问法怎么写

1. **用客户的原话**，不用内部术语：「新车多久做首保」而不是「首次保养作业周期」；
2. **一句话只问一件事**：「S7 续航多少」和「S7 冬天续航打几折」拆成两条；
3. **带上主语**：能带车型就带（「X3 首付最低多少」），不能带就用「星驰」；
4. 长度控制在 **6—18 个字**，太短会误命中，太长检索覆盖度会被稀释。

## 三、同义问法（variants）的写法

覆盖三类说法，各 1—2 条即可：

| 类型 | 例子（以「首保时间」为例） |
|---|---|
| 口语换说法 | 第一次保养、新车多久保养 |
| 带车型/场景 | S7 首保多少公里、提车后多久首保 |
| 客户关心的结果 | 首保免费吗、首保要预约吗 |

**不要**为了凑数量把近义词堆成 10 条——同义问法会参与打分，堆太多会让这条 FAQ 对无关问题也给出高置信度。

## 四、标签词表（检索用，别自由发挥）

`续航` `充电` `充电桩` `快充` `电池` `三电` `质保` `保养` `首保` `周期` `空调` `车机` `OTA` `制动` `刹车` `轮胎` `事故` `保险` `理赔` `救援` `价格` `金融` `置换` `试驾` `交付` `上牌` `购置税` `隐私` `投诉` `高风险`

新标签先在周会上确认，再写进这条规范，避免同义词分裂（「智驾」和「辅助驾驶」不要各建一个）。

## 五、答案写法

1. **先结论后条件**：「首保是 6 个月或 5000 公里，以先到为准；首保免费。」
2. **数字必须有出处**，并在 `source` 里写清楚；没有出处的数字不许写。
3. **不承诺**：不写「肯定能」「包退」「最低价」，涉及承诺的写「需门店确认」并标 `高风险` 标签。
4. **长度 1—3 句**，超过 3 句拆成两条 FAQ。
5. **不带情绪和营销话术**：不写「超值」「错过再等一年」。

## 六、状态流转

```
草稿（工单回写 / 人工新建） → 待审核 → 生效 → 停用
                                  ↑         │
                                  └── 内容过期/政策变更
```

- **待审核不参与检索**：这是硬规则，防止没核对的内容被 AI 说出去；
- 停用不删除：保留历史，便于追溯「三个月前为什么这么答」；
- 每次修改 `updated_at` 必须更新，看板会统计「本月更新 N 条」。

## 七、审核 checklist（发布前逐条打勾）

- [ ] 答案里的每个数字都能在 `source` 里找到；
- [ ] 适用车型写对了（全车型 / 具体车型）；
- [ ] 涉及价格、质保、退订的，答案里没有承诺性表述；
- [ ] 同义问法没有被别的 FAQ 也占用（避免冲突）；
- [ ] `phenomenon` 选了正确的故障现象（售后条目）；
- [ ] 负责人是真人，且知道这条内容归他维护。

## 八、维护节奏

| 触发 | 动作 |
|---|---|
| 工单解决 | 24 小时内回写为 FAQ 草稿 |
| 每周 | 看「Top 10 未命中」补内容，看「重复转人工」改答案 |
| 每月 | 抽查 10 条生效 FAQ 的 `source` 是否还有效 |
| 政策变更（价格、质保、补贴） | 当天停用旧条目，新建条目，避免 AI 用旧口径 |
| 停用超 6 个月 | 归档，不再出现在知识库列表 |
